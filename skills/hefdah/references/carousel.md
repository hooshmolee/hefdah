# کاروسل فارسی

برای موضوعی که ترتیب، مقایسه یا بازخوانی لازم دارد کاروسل پیشنهاد بده. تعداد اسلاید تابع محتواست، نه الزام؛ معمولاً پنج تا هشت اسلاید شروع مناسبی است. یک جمله را بی‌جهت به چند اسلاید نکش.

ساختار پیشنهادی: کاور با وعده روشن، زمینه لازم، یک ایده در هر اسلاید، جمع‌بندی مستقل و یک اقدام. اسلاید دوم هم بدون کاور باید معنا داشته باشد. متن کوتاه و قابل خواندن روی گوشی؛ از شمارش مکانیکی کلمات برای تضمین خوانایی استفاده نکن.

## تحویل متن

برای هر اسلاید title، body و alt فارسی بده. واقعیت‌ها به منبع کاربر متصل باشند؛ آمار نساز. متن را پیش از رندر قابل بررسی تحویل بده. برند/رنگ/فونت کاربر را رعایت کن؛ در نبود آن‌ها قالب خوانا و خنثی پیشنهاد بده.

## ساخت فایل در محیط دارای ابزار

JSON با کلید `slides` و ردیف‌های `title`, `body`, `alt` بساز. ابزار `carousel` یک HTML محلی RTL با اندازه پیشنهادی ۱۰۸۰×۱۳۵۰ می‌دهد. هیچ محتوایی به سایت سازنده ارسال نمی‌شود. HTML متون را escape می‌کند و اسکریپت خارجی ندارد.

این خروجی HTML است، نه PNG. برای فایل تصویری، در صورت وجود ابزار screenshot/render هر اسلاید را خروجی بگیر و همه را بررسی کن: اتصال حروف، ترتیب اعداد، قطع متن، فاصله و خوانایی. اگر امکان رندر نیست، متن و HTML را تحویل بده و محدودیت را کوتاه اعلام کن. هرگز PDF یا HTML را به عنوان فایل آماده بارگذاری تصویر معرفی نکن.

فونت‌های پیش‌فرض سیستم استفاده می‌شوند؛ فونت سفارشی فقط با مجوز و فایل مجاز. شماره‌گذاری، handle یا لوگو صرفاً متعلق به کاربر و با درخواست او؛ امضای اجباری hefdah نگذار. متن بلند باید تقسیم یا کوتاه شود، نه مخفی‌کردن در crop.
