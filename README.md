# hefdah | هفده

### دستیار فارسی ساخت محتوای اینستاگرام، با لحن خودت

ریلز، کپشن، استوری، کاروسل، بررسی پیج و برنامه محتوا؛ فارسی و متناسب با مخاطب ایرانی. برای شروع لازم نیست پرامپت‌نویسی بلد باشی یا اسم اسکیل‌ها را بدانی.

**لینک اشتراک:** [github.com/hooshmolee/hefdah](https://github.com/hooshmolee/hefdah) · [دانلود نسخه آزمایشی](https://github.com/hooshmolee/hefdah/releases/tag/v0.1.0)

**اگر این مخزن را به یک دستیار داده‌ای:** [از اینجا شروع کن](START-HERE.md). راهنمای شروع و سپس فقط منابع مرتبط با درخواست کاربر را بخوان. دریافت این لینک به‌تنهایی مجوز نصب، انتشار یا ارسال پیام نیست.

## شروع در Claude یا ChatGPT

لینک همین مخزن را همراه این جمله بفرست:

> می‌خوام از hefdah استفاده کنم. راهنمای START-HERE.md رو بخون و برای همین گفت‌وگو با هفده شروع کن. اگر به فایل‌ها دسترسی نداری، بهم بگو از فایل HEFDAH-CHAT.md استفاده کنم. موضوع پیجم رو ازم بپرس و کمک کن اولین محتوای قابل استفاده رو بسازم.

لینک مستقیم راهنمای شروع: [START-HERE.md](https://raw.githubusercontent.com/hooshmolee/hefdah/main/START-HERE.md). اگر مخزن تازه است یا دستیار فایل‌های GitHub را نمی‌خواند، از فایل بارگذاری‌شدنی پایین استفاده کن.

**لینک باز نشد؟** فایل [HEFDAH-CHAT.md](HEFDAH-CHAT.md) را دانلود و در گفت‌وگو بارگذاری کن، یا متن آن را کپی کن. بعد بگو «با هفده شروع کن». این فایل تمام راهنمای نوشتاری و منابع لازم را یکجا دارد؛ ابزارهای محلی را خودکار اجرا نمی‌کند.

**نصب اسکیل می‌خواهی؟** بسته مستقل [skills/hefdah](skills/hefdah) شامل یک ورودی و همه منابع است. برای نصب در محیط دارای اسکیل، [راهنمای نصب](docs/install.md) را ببین. دریافت لینک یا بارگذاری فایل را با نصب دائمی اشتباه نگیریم؛ امکانات هر نسخه از دستیار فرق می‌کند.

## فارسی‌سازی چه فرقی ایجاد می‌کند؟

- نیم‌فاصله و ایموجی پیوسته پاک نمی‌شوند؛ لحن محاوره‌ای بی‌اجازه رسمی نمی‌شود.
- هشتگ، دعوت به اقدام و اعداد فارسی/عربی/لاتین در ابزارها پشتیبانی می‌شوند.
- تومان و ریال حدس زده یا خودکار تبدیل نمی‌شوند.
- معیارهای پروفایل فرد و شرکت جدا هستند؛ داشتن سایت یا نمایش چهره شرط استفاده نیست.
- تجربه، آمار، مشتری و نتیجه برایت ساخته نمی‌شود.
- نمره «انسان بودن» یا احتمال «وایرال شدن» نمی‌فروشد؛ پیشنهادها قابل توضیح‌اند.

## ابزارهای محلی

برای کارهای نوشتاری به Python نیاز نداری. برای بررسی قابل تکرار، Python 3.10+ کافی است و بسته جانبی لازم نیست:

```sh
python skills/hefdah/scripts/hefdah.py caption examples/caption.fa.txt --json
python skills/hefdah/scripts/hefdah.py human examples/caption.fa.txt --json
python skills/hefdah/scripts/hefdah.py hook examples/reel.fa.txt --json
python skills/hefdah/scripts/hefdah.py beats examples/reel.fa.txt --wpm 150 --json
python skills/hefdah/scripts/hefdah.py swipe examples/swipe.tsv --json
python skills/hefdah/scripts/hefdah.py audit examples/insights.csv --json
```

این ابزارها بدون شبکه کار می‌کنند. تولید متن توسط Claude/ChatGPT تابع دسترسی و سیاست همان میزبان است. [راهنمای ابزارها](docs/tools.md)

## وضعیت نسخه

**۰٫۱٫۰ — آزمایشی و قابل تست.** راهنماها، ابزارها و بسته‌بندی آماده‌اند؛ ارزیابی میدانی روی کاربران ایرانی، مقایسه کور کیفیت و تست نصب زنده در تمام نسخه‌های Claude/ChatGPT هنوز انجام نشده‌اند. زمان گفتار تخمینی است؛ ۱۲۵ کاراکتر پیش‌نمایش تقریبی است؛ قواعد متغیر پلتفرم باید در مقصد بررسی شوند. [محدودیت‌ها و سازگاری](docs/compatibility.md)

هفده متن و پیشنهاد می‌سازد؛ چیزی پست، فالو یا ارسال نمی‌کند. اطلاعات حساب یا رمزت را نمی‌خواهد. هیچ داده‌ای خودکار به سایت سازنده فرستاده نمی‌شود. [حریم خصوصی](docs/privacy.md)
