# راهنمای کوتاه تست و معرفی هفده

**چی هست؟** هفده یک بسته فارسی برای کمک به نوشتن ریلز، کپشن، استوری و برنامه محتوای اینستاگرام است؛ با هدف حفظ لحن خودت.

**چطور امتحانش کنم؟** لینک مخزن را به دستیار بده و بگو «START-HERE.md رو بخون و با هفده شروع کن». اگر لینک خوانده نشد، فایل HEFDAH-CHAT.md را بارگذاری کن. یک کار واقعی از پیجت انتخاب کن: مثلاً سناریوی ریلز بعدی. نتیجه را بخوان و با لحن خودت اصلاح کن.

**بازخورد مفید:** کجا معطل شدی؟ متن چقدر شبیه خودت بود؟ چه چیزی مجبور شدی اصلاح کنی؟ آیا دوباره ازش استفاده می‌کنی؟ لازم نیست نظر مثبت بدهی یا تمام امکانات را تست کنی.

## متن استوری اختیاری، فقط بعد از استفاده واقعی

«هفده رو برای [کار واقعی که امتحان کردم] تست کردم. [نظر واقعی خودم درباره نتیجه]. اگر خواستین امتحانش کنین، لینک پروژه رو گذاشتم.»

این متن قالب است، تجربه آماده نیست؛ جاهای داخل کروشه باید با تجربه واقعی کامل شوند. اگر تست نکرده‌ای از فعل «تست کردم» استفاده نکن. نسخه آزمایشی است و رشد پیج را تضمین نمی‌کند. اگر همکاری دارای پرداخت/هدیه است، ماهیتش را روشن بیان کن.

معرفی، تگ‌کردن یا انتشار استوری شرط استفاده نیست. لینک سایت سازنده [17studio.ir](https://17studio.ir) است؛ لینک شروع خود ابزار باید همان لینک مخزن واقعی باشد. لوگو، تصویر یا گفته فرد برای تبلیغ دوباره فقط با اجازه او استفاده شود.
