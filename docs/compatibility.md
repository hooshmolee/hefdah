# سازگاری و محدودیت نسخه ۰٫۱٫۱

| مسیر | وضعیت |
|---|---|
| Python محلی | تست واقعی روی Windows با Python 3.12؛ نتیجه نهایی در verification.md |
| اسکیل خودکفا | ساختار SKILL.md و منابع محلی؛ نیازمند شناسایی/نصب در میزبان مقصد |
| فایل HEFDAH-CHAT.md | تولیدشده از منابع اصلی؛ قابل بارگذاری به عنوان راهنما، نه نصب ماندگار |
| Claude Code plugin | manifest و marketplace هر دو با CLI واقعی validate شدند؛ نصب و گفت‌وگوی مستقل هنوز آزموده نشده |
| ChatGPT/Claude چت با لینک مخزن | مسیر طراحی‌شده؛ تست گفت‌وگوی مستقل با حساب واقعی هنوز انجام نشده |
| macOS/Linux | کتابخانه استاندارد و CI چندسیستمی تعریف شده؛ فقط اجرای واقعی CI تأییدکننده است |

پیشنهادهای سبک و روبریک پروفایل کالیبراسیون میدانی ندارند. corpus ۳۰۰تایی، ۳۰ خوانش و پایلوت پنج اینفلوئنسر در این نسخه جمع‌آوری/انجام نشده‌اند. مجموعه تست نرم‌افزار جای پژوهش اثربخشی را نمی‌گیرد.

زمان گفتار تخمین بر اساس واژه، بسط ساده عدد و مکث است؛ نرخ پیش‌فرض نتیجه پژوهش فارسی نیست. اعشار به شکل ساده خوانده می‌شود و تلفظ اختصارات، واحد و اعداد بلند ممکن است متفاوت باشد. برای ضبط نهایی بخوان و زمان بگیر.

قدرت تشخیص CTA و هشتگ heuristic است، نه فهم کامل زبان. بررسی‌های مرز عدد از حدس خاموش جلوگیری می‌کنند؛ قالب مبهم خطا می‌دهد. preview کپشن دقیقاً بازسازی UI نیست. اعتبار سقف هشتگ/فیلدها باید در مقصد بررسی شود.

اسکیل به امکانات مدل و محیط وابسته است؛ دادن لینک، مدل را بازآموزی نمی‌کند. فایل‌های بازنشده و اسکریپت‌های اجرا‌نشده نباید در گزارش «انجام‌شده» نامیده شوند. استفاده از میزبان باید مطابق دسترسی مجاز آن سرویس باشد.

کاروسل خروجی HTML است؛ برای PNG به رندرگر موجود نیاز دارد. هیچ عدد بازدید، نرخ رشد، رضایت مشتری یا داستان موفقیت ساختگی به عنوان اثبات محصول ارائه نشده است.
