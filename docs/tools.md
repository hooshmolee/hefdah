# ابزارهای محلی

Python 3.10+، بدون pip، شبکه، مدل یا API key. از ریشه مخزن اجرا کن؛ فایل UTF-8 یا `-` برای stdin بده. خروجی ساختاریافته JSON است؛ `--json` نیز پذیرفته می‌شود. روی Windows در صورت مشکل نمایش از `python -X utf8` استفاده کن.

| فرمان | کار واقعی | محدودیت |
|---|---|---|
| normalize | ی/ک خارج از بخش محافظت‌شده؛ گزارش کنترل جهت | اصلاح کامل املایی نیست |
| human | normalize و پیشنهاد کلیشه‌ها | بازنویسی معنایی/تشخیص AI انجام نمی‌دهد |
| caption | هشتگ فارسی، CTA تقریبی، طول و پیش‌نمایش | sarcasm و جملات پیچیده نیازمند قضاوت‌اند |
| hook | هشدار مقدمه، طول و جزئیات | امتیاز یا پیش‌بینی بازدید ندارد |
| beats | بسط عدد و تخمین خوانش | گوینده/واژه تخصصی نیازمند کالیبراسیون |
| swipe | views/median همان حساب | داده هم‌سن/هم‌فرمت را ورودی‌دهنده تعیین می‌کند |
| audit | نسبت‌های اعشاری و تشخیص کمبود داده | تحلیل علت و رتبه‌بندی ناهم‌پنجره انجام نمی‌دهد |
| carousel | HTML محلی RTL از JSON | PNG تولید نمی‌کند؛ خروجی تصویر جدا رندر شود |
| context-init | ایجاد پوشه جدید برند | بازنویسی نمی‌کند؛ نام برند صریح لازم است |
| context-show | خواندن فقط برند انتخابی | خروجی را در فضای عمومی به اشتراک نگذار |

نمونه‌ها در پوشه `examples` ساختگی و صرفاً برای آزمایش‌اند:

```sh
python skills/hefdah/scripts/hefdah.py carousel examples/carousel.json -o carousel.html
python skills/hefdah/scripts/hefdah.py context-init clients --client my-page
python skills/hefdah/scripts/hefdah.py context-show clients --client my-page
```

`-o` فقط فایل جدید می‌سازد؛ خروجی موجود بازنویسی نمی‌شود. داده ورودی بزرگ‌تر از یک میلیون نویسه رد می‌شود. خطای عدد مبهم مثل `12,5` باید با قالب روشن `12.5` یا `۱۲٫۵` اصلاح شود؛ ابزار حدس نمی‌زند. درصد خروجی parse مقدار درصد است، مثلاً ۴۵٪ → 45؛ نرخ‌های audit نسبت‌اند، مثلاً 0.02 یعنی ۲٪.

با «می‌خواهم»، «میخوام» و «می‌خوام» به عنوان شیوه‌های متفاوت نگارش برخورد کن؛ ابزار خودکار رسمیت را عوض نمی‌کند. رشته‌های داخل گیومه، لینک، کد و ایمیل در normalize محافظت می‌شوند؛ نگارش درون آن‌ها نیازمند بررسی دستی است.
