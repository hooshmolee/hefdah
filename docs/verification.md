# گزارش بررسی نسخه ۰٫۱٫۰

تاریخ: ۲۰۲۶-۱۰-۲۱. این گزارش آزمون نرم‌افزار و بسته‌بندی است، نه اثبات اثربخشی محتوا در اینستاگرام.

## اجراشده

- Windows، Python 3.12.14: مجموعه `python -X utf8 -m unittest discover -s tests -v` شامل ۲۰ تست؛ ۱۹ پاس و یک skip به علت نبود مجوز ایجاد symlink در محیط محدود. تست‌های عدد، حفظ نیم‌فاصله/emoji/لینک، کنترل جهت، CTA فارسی، مقدار غایب/صفر، جداسازی برند، XSS قالب، نصب بدون بازنویسی و اجرای ZIP پس از استخراج پوشش داده شدند.
- اعتبارسنج استاندارد skill-creator روی هر ۱۴ پوشه: معتبر. ورودی اصلی + ۱۳ میان‌بر؛ ۱۳ حالت کاربردی.
- `claude plugin validate .claude-plugin/plugin.json`: پاس. `claude plugin validate .`: marketplace پاس بدون هشدار پس از افزودن توضیح.
- فایل چت و میان‌برها با `scripts/build_release.py --check` مطابق منابع اصلی‌اند.
- ZIP کامل و ZIP اسکیل خودکفا ساخته شدند؛ فایل‌های واقعی مشتری، پوشه Git، cache و وابستگی اعتبارسنج محلی در ZIP نیستند. آزمون واقعی اجرا از ZIP استخراج‌شده انجام شد.
- نمونه پنج‌اسلایدی کاروسل با Chrome headless رندر و همه پنج تصویر بازبینی شد؛ متن فارسی خوانا و overflow گزارش نشد. شماره‌گذاری راست‌به‌چپ اصلاح شد و به صورت «۱ از ۵» نمایش داده می‌شود.

فقط برای اجرای اعتبارسنج استاندارد، PyYAML 6.0.3 در پوشه محلیِ نادیده‌گرفته‌شده نصب شد؛ این وابستگی اجرای محصول نیست و در بسته انتشار قرار ندارد. ابزارهای hefdah فقط کتابخانه استاندارد Python را مصرف می‌کنند.

## هنوز انجام‌نشده

- نصب و گفت‌وگوی مستقل روی حساب واقعی Claude/ChatGPT؛ validate ساختار به معنی این آزمون نیست.
- پایلوت اینفلوئنسرها، corpus فارسی، مقایسه کور و کالیبراسیون گفتار؛ هیچ نتیجه اثربخشی یا رضایت کاربر ساخته نشده است.
- انتشار خودکار، اتصال اینستاگرام، پیام به افراد و اقدام اجتماعی؛ محصول چنین اجرایی ندارد.
- تست symlink در Windows محدود؛ CI روی محیط‌های دیگر برای این مورد و سازگاری چندسیستمی تعریف شده است. وضعیت اجراهای واقعی CI باید جدا از تعریف workflow خوانده شود.

نسخه برای آزمودن کاربرد واقعی آماده است؛ هنوز محصول اعتبارسنجی‌شده میدانی نیست.
